# Summary

We inspected the Riverside Road bridge deck in September 2026. The deck is in fair condition.
Chloride levels at one core location exceed the corrosion threshold, so we recommend a targeted
repair within twelve months.

# Findings

The inspection covered the deck soffit, parapets and six core locations.

| Core | Location       | Depth (mm) | Chloride (%) |
|------|----------------|-----------:|-------------:|
| C1   | Span 1, north  | 50         | 0.12         |
| C2   | Span 1, south  | 50         | 0.31         |
| C3   | Span 2, centre | 50         | 0.45         |

Table: Chloride content by core location

Values above 0.40% indicate a high risk of reinforcement corrosion.

## Recommendations

1. Repair the area around core C3 within twelve months.
2. Re-test chloride levels in 2028.
3. Inspect the expansion joints at the next routine visit.
